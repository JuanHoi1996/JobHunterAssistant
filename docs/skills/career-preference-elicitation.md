# 择业偏好 Elicitation 协议

> 本协议通过结构化采访，为当事人量身定制一份**可独立打分排序**的择业 SKILL（门控、权重、0/5/10 锚点、公式与多岗流程）。访谈证据进附录，不替代评分引擎。

---

## 0. 核心前提

### 0.1 为什么不能直接问「你想要什么」

陈述偏好与显示偏好经常冲突。人们会：

- 说自己要「意义」，实际选「年薪」
- 说自己要「稳定」，实际忍受不了无聊
- 说自己要「权力」，实际怕承担责任
- 根本不知道「居然能图这个」的选项存在

因此**禁止以开放式「你的职业目标是什么」作为主问题**。正确顺序：

```
1. 扩可能性空间（让用户知道有什么可图）
2. 用强制权衡揭示相对重要性
3. 用历史决策校验显示偏好
4. 用反模式与硬约束收口
5. 输出可打分的专属择业 SKILL（门控 + 锚点 + 公式 + 多岗工作流；证据进附录）
```



### 0.2 本协议在整条链路中的位置

```
本协议（采访）
    → 生成「该用户专属择业 SKILL」
        → 之后该用户的 Agent 用这份 SKILL 评估岗位 / Offer
```

- **不**预设用户图权、图利、图稳或图任何特定东西。
- 本协议自洽：仅凭采访即可生成专属 SKILL；用户若另有简历等材料，可在生成后自行组合使用。



### 0.3 Agent 行为准则

1. **一次只问 1–2 个问题**，等用户答完再继续。
2. **追问具体场景**，拒绝抽象形容词（「有挑战性」「氛围好」必须落到可观察行为）。
3. **主动挑战自洽性**：前后矛盾时温和指出，请用户裁决。
4. **不替用户做价值判断**：可指出 trade-off，不可说「你应该更看重 X」。
5. **不对任何欲求做道德或高低排序**：只记录偏好强度、trade-off 与可知代价。
6. **采访结束前必须输出完整的专属择业 SKILL**（见第 5 节），不可只给口头总结。

## 1. 可能性空间：先让用户知道「能图什么」

目的不是让用户全选，而是防止「不知道居然能图这个」导致偏好被过早截断。

向用户展示（可口语化，但下列主维不可删）：

### 1.1 名（Status / Recognition）

- 对外声誉、行业知名度、媒体可见度
- 头衔/品牌光环（「我在 XX」能换来的社交溢价）
- 学术/专业共同体中的承认
- 「被看见」本身（不等于对内实权）



### 1.2 利（Material Return）——拆开问时抓三类

口头「要钱」常混着不同东西；访谈时至少分清：


| 子类型       | 含义                | 典型形态                          |
| --------- | ----------------- | ----------------------------- |
| **现金**    | 可立刻花或算进年包的钱       | 底薪、奖金、提成、总包现金部分               |
| **股权/期权** | 上行不对称、兑现不确定       | 期权、股票、分红权、Carry               |
| **隐形福利**  | 不进工资条、但极大改变真实生活水平 | 户口、住房、子女教育、医疗、签证、公积金、退休、高标准补贴 |




### 1.3 权（Power）——务必拆开问

「我要权」歧义极大。下表按来源、代价与衰减区分类型：


| 类型              | 含义                          | 常见代价 / 衰减             |
| --------------- | --------------------------- | --------------------- |
| **对内支配权**       | 让事情按自己意志发生（分配资源、定规则、拍板）     | 责任与问责绑定；失去位子则权力常一并消失  |
| **对内自主权**       | 不被随意支配（能 Say No）            | 未必能推动大局；有时以缩小管辖范围为代价  |
| **对内否决权**       | 能卡住别人的流程（合规、审批、风控）          | 易依赖制度节点；制度改革或被绕过则快速贬值 |
| **对外影响力**       | 塑造客户、市场、行业或政策认知             | 不一定等于对内官大；维护成本高       |
| **核心资源持有**      | 客户/技术/资质等写在自己名下，离开仍可带走或仍被依赖 | 构建慢；组织可能试图收归          |
| **信息通道 / 近身枢纽** | 控制关键信息流向决策层                 | 架构或汇报线一变就可能清零         |




### 1.4 稳（Security）——务必拆开问

口头「稳」常混着来源完全不同的安全感：


| 子类型        | 含义                  | 典型形态                  | 安全感来自             |
| ---------- | ------------------- | --------------------- | ----------------- |
| **制度编制型**  | 法理/制度上难以被随意解雇       | 公务员、事业编制、部分体制内正式身份    | 制度保护，与个人是否不可替代无关  |
| **平台存续型**  | 雇主或行业本身不太可能消失       | 公用事业、大型刚需机构、垄断性行业     | 「单位还在」；不保证你的位子还在  |
| **个人可携带型** | 离开后技能与信誉仍能换到下一家     | 通用硬技能、可验证作品、跨机构声誉     | 「我」还在，而不是「这个饭碗」还在 |
| **议价锁定型**  | 因你掌握关键资源，对方更换你的成本极高 | 核心客户关系、关键系统、稀缺资质在个人手里 | 对方对你的依赖，而非制度对你的保护 |


这四类可以并存，但不可互相替代。采访时须问清主锚落在哪一类；编码方式见 §3.1。

常见误认：

- 以为要编制，实际要的是焦虑消退或收入下限确定
- 以为要「不可替代」，实际要的是不被突然解雇
- 以为单位够大就等于个人够稳

其他常与「稳」绑在一起、宜单列追问的：

- 收入下限的确定性（哪怕上限不高）
- 地理/签证/家庭约束下的可持续性
- 「最坏情况下我不会完蛋」的底线感



### 1.5 趣 / 智识（Intellectual & Aesthetic）

- 问题本身是否有趣；是否处于认知前沿
- 审美满足（优雅的系统、漂亮的工艺）
- 「胜负手」可量化的游戏感（分数、实验、排行榜、盈亏）
- 访谈提示：有人要「解题爽」，有人要「计分板」——可并存，冲突剧烈时再拆子权重



### 1.6 义 / 影响（Meaning / Impact）

- 对社会/特定人群的可感知影响
- 与自我叙事一致（「我是什么样的人」）
- 宗教/政治/伦理立场的兼容；留下作品/遗产的冲动
- 访谈提示：「改变世界」与「对自己交代得过去」不是同一回事



### 1.7 人 / 场（People & Environment）

- 导师质量 vs 同事智力密度（常打架，勿混成「氛围好」）
- 是否厌恶办公室政治 / 是否享受政治
- 团队气质（狼性 / 学院 / 官僚 / 帮派）
- 归属感、圈子、恋爱/婚恋市场外部性



### 1.8 生（Lifestyle）

- 工时、出差、on-call、通勤（含时薪感）
- 城市、气候、距离家人
- 身心健康成本
- 「下班后还是不是自己」
- 访谈提示：工时、城市、健康三者经常互斥，冲突剧烈时再拆子权重



### 1.9 「我居然能图这个」备用槽

采访中若用户说出地图之外的欲求，**必须新增为正式维度**，不可强行塞进上述分类。例如：

- 报复性证明（打脸某个过去的人/机构）
- 收集稀缺体验（「这辈子要待过某种台子」）
- 身份跃迁（阶级、国籍、口音圈层）
- 控制不确定性本身带来的兴奋
- 反向：刻意选择「看起来差」的路以保持低预期

展示完后问：

> 「上面这些，有没有哪个你之前没认真想过、但突然觉得『嗯？这个好像也重要』？有没有完全没列出来、但你隐隐在乎的？」

## 2. 采访提纲（分六幕）

总时长建议：45–90 分钟，可分多次。

### 开场：先判生涯阶段（必做，30 秒）

在第一幕之前先确认：

> 「你现在更接近哪一种：还在求学/应届求职、有过实习但几乎没有全职、还是已经有一年以上全职经历？」


| 阶段             | 代号     | 第一幕用哪套题                    |
| -------------- | ------ | -------------------------- |
| 在读 / 应届 / 仅短实习 | **E0** | E0 题库（学业、实习、项目、家庭压力中的显示偏好） |
| 全职约 1–3 年      | **E1** | 可混用；优先全职故事，不足处用 E0 补       |
| 全职 3 年以上       | **E2** | E2 题库（工作决策中的显示偏好）          |


**执行规则**：

- 判定阶段后，**必须**改用对应题库；禁止对 E0 用户继续使用 E2 的「多年全职决策」问法。
- 第二幕强制权衡对所有阶段相同，是 elicitation 的主骨架。
- E0 可将「羡慕某人」作入口，但必须追问到名 / 利 / 权 / 稳 / 趣 / 义 / 人 / 生中的具体维度。
- E0 产出的权重置信度默认更低：专属 SKILL 须写明「建议在第一份全职工作 12–24 个月后重跑本协议」。经历材料少时仍应完成访谈与出稿，用权衡与否决清单把模糊偏好收束成可执行权重。

---



### 第一幕：冷启动——用故事，不用形容词

**目标**：拿到显示偏好原材料，暂不让用户自我定位。

#### E2 题库（有全职经历）

必问：

1. 「过去 5 年里，你做过的最『值』的一个职业相关决定是什么？事后看，它值在哪？」
2. 「做过的最后悔的职业相关决定？后悔的真正原因是什么（钱？面子？无聊？被支配？怕被开除？错过窗口？）？」
3. 「有没有一份你差点接受、最后拒绝的 offer？拒绝的那一瞬间，脑子里闪过的是什么？」
4. 「有没有一份『别人觉得很好、你待着却很难受』的经历？难受的具体触发点是什么？」

选问：

- 「如果把你过去的选择做成一条时间线，有没有一条反复出现的回避模式？」
- 「你羡慕过谁的职业状态？羡慕的是他们的哪一块，不是整个人。」



#### E0 题库（应届 / 在读 / 经历很薄）

全职故事不够时，**改从这些「已经做过的选择」里挖显示偏好**——材料更碎，但一样是行为，不是口号。

必问（至少覆盖 4 题；有实习经历者优先问实习相关）：

1. 「选专业 / 选方向 / 选课题时，若曾和『更稳/更赚/父母更满意』的选项打架，你最后怎么走的？当时真正怕失去的是什么？」
2. 「有没有一段实习、兼职、竞赛或项目，是你主动延长或反复回去的？留下的理由是内容、人、名头、钱，还是别的？」
3. 「有没有一段你很快想逃的经历（课、实习、学生工作、家庭安排的体验）？讨厌的具体触发点是什么机制？」
4. 「秋招/实习投递里：你认真准备过哪些、投了但没用心的有哪些、拿到后拒绝或犹豫的有哪些？拒绝/犹豫那一刻脑子里闪过什么？」
5. 「若还没有任何 offer：在你认真了解过的岗位里，删掉『我可能进不去』之后，仍不想去的是哪类？不想的是什么机制？」

选问（用于加厚，不可替代必问）：

- 「你羡慕过谁的状态？只说一个人，并拆开：你羡慕的是名、利、权、稳、趣、义、人、生里的哪一两样？」
- 「若父母/伴侣的理想路径和你隐隐想要的不一致，冲突点通常在哪一维？」
- 「你自愿熬夜做、且没有绩点/证书压力的事，通常是什么？你主动拖延、一做就空的事又是什么？」
- 「小组作业里你抢着做和甩给别人的各是什么？这往往暴露趣/人/支配欲，而非能力。」
- 「如果明年此刻你过得很难受，你猜最可能是哪种难受：穷、无聊、被管死、没名、不稳、还是身边没人？」

**E0 追问纪律**：用户若只答「我羡慕咨询/考公/大厂」，必须追问到维度，例如：

> 「你羡慕的是牌子、是离开后的选择权、是父母能交代、是工作内容本身，还是『听起来正常』？」



#### E1 题库（全职不久）

先用 E2 的 1–2 题；若答不出就切 E0。材料不够时不要硬编五年职业叙事。

---



### 第二幕：强制权衡——逼出排序

**目标**：相对权重，而不是「全都要」。

规则：每次 **A vs B**，不允许「都重要」。若坚持都重要：「只能保一个、另一个归零，你保哪个？」

#### 2.1 顶层权衡卡（每张必做）


| #   | 选项 A                    | 选项 B                   |
| --- | ----------------------- | ---------------------- |
| 1   | 年包高 40%，但完全没有拍板权，是高级执行  | 年包低 30%，但你是事实上的规则制定者之一 |
| 2   | 公司名头极响，出去被人高看；内部你是螺丝钉   | 名头普通；你走了业务会抖一下         |
| 3   | 制度上很难开除你（类编制），路径清晰但上限一般 | 上行极大、也可能被裁或清零，三年看不出胜负  |
| 4   | 对外影响力很大（客户/行业认你），对内官很小  | 对内官大（管人管预算），对外没人知道你    |
| 5   | 工作本身让你上瘾，但总包一般、社会地位一般   | 工作无聊，但钱和牌子都到位          |
| 6   | 技能高度可携带，随时能走            | 当前平台利益极大，但离开几乎归零       |
| 7   | 时间自由（少加班、少出差），收入中上      | 时间被工作占满，收入显著更高         |
| 8   | 你认同这件事的社会意义             | 你觉得意义一般，但能积累你最看重的另一种资本 |




#### 2.2 细分权衡卡（按第一幕信号选做）

若流露「要钱」：

- 高现金确定性 vs 高股权上行
- 账面工资高 vs 隐形福利（户口/签证/住房）更好
- 高底薪低奖金 vs 低底薪高绩效浮动

若流露「要权」：

- 支配权 vs 自主权（能指挥别人 vs 自己不被指挥）
- 对内官大 vs 对外影响力大
- 能拍板做事 vs 能卡住别人做事（否决/审批型位置）
- （可选）资源写在自己名下 vs 靠近决策层的信息枢纽

若流露「要稳」——**必须继续拆**：

- 有编制/类编制、很难开除，但个人可替代、调岗听安排  
vs 没有编制保护，但你走了组织很痛
- 行业/单位本身很稳，但裁员时你可能第一批  
vs 行业波动，但你的技能到哪都能接住
- 地理与生活高度确定  
vs 职业跃迁机会更大但常搬家/常变动

若流露「要人」：

- 导师极强但团队氛围残酷 vs 氛围舒服但成长慢
- 圈子能带来婚恋/社会资源 vs 工作内容本身更优但圈子弱

若流露「要趣」：

- 智识刺激但绩效难量化 vs 绩效清晰但智力含量一般
- 长期深耕一个谜题 vs 不断切换新战场



### 第三幕：反模式——你绝对不碰什么

负面偏好往往比正面偏好更稳定。

必问：

1. 「什么样的工作，给双倍钱你也不干？具体讨厌的是什么机制，不是什么行业标签。」
2. 「你最受不了哪种上级 / 导师 / 合作者？哪种同事或队友？」（E0 可改问老师、实习师傅、组长）
3. 「有没有一种『成功样板』是你明确不想变成的？」
4. 「你能接受暂时缺哪一样：名 / 利 / 权 / 稳 / 趣 / 义 / 人 / 生？哪个最不能暂时没有？」

输出：**硬性否决清单** + **软性厌恶清单**。

### 第四幕：约束与阶段——地图上的墙

必问：

1. 「地理/签证/家庭/健康上，有没有硬约束？哪些是真硬，哪些其实可谈？」
2. 「你现在更像『先攒某种资本』还是『该把已有资本兑现』？你说的资本是哪一种？」（E0 常见如学历信号、实习履历、可展示作品——按用户原意记录）
3. 「未来 3 年，你能忍受的最坏财务情况是什么？最坏时间投入是什么？」
4. 「如果这次选择错了，你的退出成本有多高？谁会替你承担后果？」
5. （E0 加问）「家庭对『第一份工作』有没有不能碰的雷区？那是他们的雷区，还是你也认的雷区？」



### 第五幕：自洽性压力测试

根据前四幕草稿，制造 2–3 个矛盾场景。示例：

> 「你前面说最看重『制度上的稳』（很难被开除），但又羡慕能自己说了算的人。有编制的位置通常更难自己说了算——这两边撞车时，你真实的第一反应站哪边？」

改口记录为 **修正后的权重**；改口往往是 elicitation 成功的标志。

### 第六幕：命名与叙事

必问：

1. 「如果用一句话描述你的效用函数（不是职位目标），会是什么？」
  例：「先把生活波动压到能睡得着，再谈别的」「最大化时薪与可控性」「在有趣的问题里拿到超额回报」「要被行业看见」
2. 「三年后，什么样的『普通周二下午』会让你觉得：嗯，选对了？」
3. 「谁的评价你在乎？谁的评价你假装在乎？」

## 3. 从采访到专属 SKILL：编码规则



### 3.1 主效用维度（默认编码表）

**如何决定一列还是子类型/子权重**：


| 档   | 条件                | 编码方式              | 例                 |
| --- | ----------------- | ----------------- | ----------------- |
| A   | 强制权衡时经常互斥，且常被独立赋权 | 默认多列              | 支配 / 自主 / 否决 / 对外 |
| B   | 一人通常只认一个主类型       | 一列 + 子类型备注；必要时子权重 | 稳 K               |
| C   | 可并存、强度不同          | 一列 + 子权重          | 利 M = 现金/股权/隐形    |
| D   | 访谈中点到、但未成主锚       | 不写入权重表            | —                 |
| E   | 访谈中成为主锚、又不在默认表内   | 写入自定义维 X 或临时加列    | 如核心资源持有、信息通道      |


默认权重表：


| 代码     | 维度          | 说明                          |
| ------ | ----------- | --------------------------- |
| S      | 名 Status    | 外部承认、品牌、头衔                  |
| M      | 利 Money     | 子权重：现金 / 股权 / 隐形福利          |
| P_dom  | 支配权         | 对内让事情发生                     |
| P_aut  | 自主权         | 不被支配                        |
| P_veto | 否决权         | 能卡住流程                       |
| P_ext  | 对外影响力       | 客户/市场/行业                    |
| K      | 稳 Security  | 须注明主子类型（编制型/平台型/可携带型/议价锁定型） |
| I      | 趣 Intellect | 智识刺激、游戏感；冲突剧烈时可再拆子权重        |
| G      | 义 Meaning   | 意义、叙事一致                     |
| H      | 人 People    | 同事、导师、圈子、场域；冲突剧烈时可再拆子权重     |
| L      | 生 Lifestyle | 时间、地理、健康；冲突剧烈时可再拆子权重        |
| X      | 自定义         | 采访中新确认的主锚                   |


> 名利权稳趣义人生 = S / M / P* / K / I / G / H / L。权拆成多列，因同一句「我要权」常指向不同对象；稳保持一列，因子类型多为互斥主锚而非并行赋权。



### 3.2 权重分配规则

1. 所有启用维度（含启用的 X）权重之和 = 100。
2. 来源优先级：**强制权衡 > 历史显示偏好 > 口头宣言**。
3. 任一维度权重 ≥ 30 → **主锚**；≤ 5 → **可忽略**（可合并或降采样）。
4. 权衡中反复被牺牲的维，即使口头「也重要」，权重不得虚高。
5. 利：`M` 内部子权重 `现金 + 股权 + 隐形 = 1`。
6. 稳：备注写清主子类型；若用户明确混要多种，用子权重，例如 `K = 0.6·编制型 + 0.4·可携带型`。
7. 任一合法偏好均可获高权重；若某权类型衰减较快，可在备注写明常见代价，供用户知情，不作价值贬斥。
8. 人 / 生 / 趣 默认各一列；仅当压力测试暴露稳定互斥时，再拆子权重。



### 3.3 生成物必须是「可打分的 SKILL」，不是访谈纪要

专属择业 SKILL 的读者是**后续负责评岗的 Agent**。正文必须能独立完成：接收多个岗位 → 否决检查 → 分维打分 → 加权排序。

**正文必有（按此顺序）**：

1. YAML `description`：写清触发场景（评估 offer、岗位排序、JD 对比等）
2. **何时使用 / Agent 角色**（3–5 句）
3. **硬性否决（门控）**：触碰即淘汰；**门控项不进入权重加总**
4. **评分引擎**：公式 + 启用维 + **每一维的 0/5/10 锚点**（用该用户语言写清「什么叫高供给」）
5. **软性扣分规则**：可量化分值或档位
6. **并列打破规则**：来自权衡裁决的词典序
7. **多岗位工作流** + **单岗报告模板** + **对比表模板**
8. **信息不足时怎么做**

**附录才放（勿放正文开头）**：显示偏好证据、自洽性修正、普通周二测试、生涯阶段与置信度

**合格自检**：另开干净对话，只贴该 SKILL + 两份 JD，应能直接给出带数字的排序；做不到则仍是纪要。

```
若触碰任一硬性否决 → 淘汰，不计分
否则：效用分 = Σ(供给分_i × 权重_i)/100 − 软性扣分
供给分_i ∈ [0,10]，按该维 0/5/10 锚点估计
```



### 3.4 原型标签（可选、弱提示）

可在附录写「较接近：……」，仅作速记。禁止用原型替代权重；禁止宣称某原型更高级。

## 7. 反模式（本协议自己的）

1. **变成鸡汤价值观测试**——不谈 trade-off 就没有决策价值。
2. **用原型标签替代权重**——「你是稳态型」一句话不能驱动打分。
3. **把采访者自己的美学灌给用户**——用户的权重以采访证据为准，不以 Agent 的价值偏好为准。
4. **生成没有否决清单的 SKILL**——只有加分项无法排序。
5. **一次倒完所有问题**——elicitation 是对话，不是表单倾倒。
6. **把采访本身当成终点、不输出专属 SKILL**——本协议的完整产品是可独立使用的择业 SKILL。
7. **对 E0 用户仍使用 E2 的多年全职问法**——经历不够时硬问，容易得到编造或冷场；应切换 E0 题库。
8. **对 E0 只问「你羡慕谁」就收工**——羡慕是入口，不是结论；不追到名利权稳趣义人生中的具体维，等于没做 elicitation。
9. **因材料少而拒绝给 E0 出 SKILL**——材料少时更需用权衡与否决清单收束偏好；应出稿并标明较低置信度与重跑时间。
10. **输出像访谈纪要**——权重表 + 定性 SOP + 「高/中/低」模板，无法让下游 Agent 对多岗做可复核的数字排序。证据放正文开头、缺 0/5/10 锚点、软性厌恶无扣分分值，都算此类失败。
11. **门控与权重双重计价**——人身安全等已是硬性否决，就不要再占权重表额度「加分」。
